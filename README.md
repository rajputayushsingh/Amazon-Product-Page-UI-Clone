# 🛒 Amazon Product Page UI Clone

A responsive **Amazon-inspired Product Page UI Clone** built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of an e-commerce product page with a navigation bar, product gallery, pricing section, offers, delivery details, and interactive buttons.

> **Note:** This project is created for educational and portfolio purposes. It is not affiliated with or endorsed by Amazon.

---

## 🚀 Live Features

* 🛍️ Amazon-style navigation bar
* 🔍 Search bar UI
* 📍 Delivery location section
* 🖼️ Product image gallery
* 🔄 Interactive product thumbnail switching
* ⭐ Product rating and reviews section
* 💰 Product price and discount display
* 🎁 Offers and EMI section
* 📦 Delivery and stock information
* 🔢 Product quantity selector
* 🛒 Add to Cart interaction
* ⚡ Buy Now interaction
* 📱 Responsive design for mobile and desktop
* 🦶 Professional footer section

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/rajputayushsingh/Amazon-Product-Page-UI-Clone.git
```

### 2. Open the project

```bash
cd Amazon-Product-Page-UI-Clone
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the project

Open `index.html` using **Live Server** in VS Code.

You can also open `index.html` directly in your browser.
